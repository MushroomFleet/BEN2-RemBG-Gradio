# BEN2 RemBG Gradio 🚀🎨

BEN2 RemBG Gradio is an innovative tool that leverages a Gradio interface for seamless background removal with powerful CUDA acceleration. This project is designed for users who require efficiency and cutting-edge performance in image processing.

## Model Author

Check out the original model by [PramaLLC/BEN2](https://huggingface.co/PramaLLC/BEN2).

## Installation 🔧

Follow these steps to set up the project:

1. Clone the repository:
   ```
   git clone GITHUB_REPO_URL_PLACEHOLDER
   ```
2. Navigate to the project directory.
3. Run the installation script:
   ```
   install.bat
   ```

## CUDA Support ⚡️🔥

This project supports CUDA acceleration for enhanced performance. Ensure that your system has a compatible NVIDIA GPU with the necessary drivers installed.

## Starting the Application 🚀

To start the application, simply run:
   ```
   run-gradio.bat
   ```

- **User-Friendly Interface:** Built with Gradio for an intuitive experience.
